# 🚀 Smartik — Академия Дошкольника

**Smartik (Смартик)** — это ультра-легкое кроссплатформенное десктопное приложение для обучения и развития детей дошкольного возраста. Проект построен на базе передового стека **.NET 10**, **Blazor** и **Photino**, что обеспечивает мгновенный запуск, минимальное потребление оперативной памяти и интерактивный интерфейс.

---

## 🎈 Основные возможности и тренажеры

Приложение включает в себя интерактивные модули с адаптивной версткой для юных отличников:

* **🔢 Умный счет** — Тренажер примеров на сложение и вычитание, стилизованный под привычную тетрадную клеточку. Поддерживает настройку количества заданий, режим решения на скорость и генерацию бланков для печати.
* **🧠 Логика и неравенства** — Задачи на подстановку пропущенных чисел и правильных знаков сравнения (`>`, `<`, `=`).
* **🎯 Фокус-счет** — Специальный режим концентрации: примеры выводятся крупным шрифтом по одной карточке на экран, исключая рассеивание внимания.
* **💡 Фокус-логика** — Логические задания в фокус-режиме «один экран — одна задача» для максимального вовлечения ребенка.

## 🛠 Технологический стек (Актуальность: 2026)

* **Runtime:** [.NET 10](https://microsoft.com) (C# / Razor)
* **Desktop Shell:** [Photino.Blazor](https://tryphotino.io) — современная альтернатива Electron. Использует нативный движок операционной системы, благодаря чему размер собранного приложения исчисляется мегабайтами, а не сотнями мегабайт.
* **UI Components:** [Radzen.Blazor](https://radzen.com) — адаптивные компоненты, дизайн-система и темы оформления.

## 💻 Системные требования (Windows)

Приложение поставляется в виде **одного независимого исполняемого файла (`.exe`)**, который не требует установки и работает по принципу Portable.

* **Операционная система:** Windows 10 или Windows 11 (64-bit).
* **Предустановленный рантайм:** .NET 10 **НЕ требуется** (все необходимые компоненты платформы уже вшиты внутрь самого `.exe`).
* **Компоненты ОС:** Требуется наличие системного компонента **WebView2 Runtime** (в Windows 11 он встроен изначально; в Windows 10 обычно устанавливается автоматически вместе с обновлениями или браузером Edge).
* **Оперативная память:** от 512 МБ (само приложение потребляет рекордно малые 60-80 МБ RAM).

## 🚀 Как запустить локально (для разработчиков)

1. Убедитесь, что у вас установлен **.NET 10 SDK**.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd Smartik
   ```
3. Перейдите в папку десктопного проекта и запустите его:
   ```bash
   dotnet run --project src/Smartik.Desktop/Smartik.Desktop.csproj
   ```

## 📦 Сборка релизной версии (CI/CD)

В репозитории настроен автоматический пайплайн сборки через **GitHub Actions**. 
Чтобы сгенерировать готовый исполняемый `.exe` файл для Windows в один архив:

1. Создайте и отправьте новый тег в Git:
   ```bash
   git tag v1.0.0
   git push --tags
   ```
2. GitHub Actions автоматически соберет проект, упакует его в `Smartik-Windows.zip` (включая все ресурсы и рантайм .NET) и прикрепит его к релизу на странице **Releases**.
